# PigeonDaycare_GameJam2025
My submission for the Games Now! Autumn 2025 game jam.

Project 49: A simulation game where you take care of a cute pigeon. You will have to feed them, wash them and play with them; making sure that their needs never drop to zero. 

Taking inspiration from games like Nintendogs and Tamagotchi 🐦‍⬛
